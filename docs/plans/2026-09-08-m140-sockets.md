# M140 Portable sockets - Implementation Plan

**Goal:** a `Network.Socket` module whose constants and `sockaddr` layout
live in the runtime (portable by construction), ahttpd rewritten over it
so the httpd harness runs on Linux CI too, and per-call tracing that can
finally characterise the arm64 inter-connection delivery gap.

**Architecture:** six IO primitives in `runtime/ahc_rts.c` - listen,
accept, connect (numeric IPv4), recv, send, close - over nonblocking fds
the runtime already knows how to park on (M127's `waitRead`/`waitWrite`).
Failures raise `IOError`s with the errno-derived type (M137). Payloads
are `Text` (the packed byte type; invalid UTF-8 normalises to U+FFFD, so
this is a text-protocol socket, documented). `AHC_SOCKET_DEBUG=1` logs
every recv/send with its result and errno to stderr.

## Phase A - runtime + builtins
- `primSockListen :: Int -> Int -> IO Int` (port, backlog): socket, SO_REUSEADDR, bind INADDR_ANY, listen, O_NONBLOCK; raises on failure with location "listenOn".
- `primSockAccept :: Int -> IO Int`: accept4-equivalent (accept + O_NONBLOCK on the new fd); -1 when it would block (EAGAIN/EWOULDBLOCK); raises otherwise.
- `primSockConnect :: Text -> Int -> IO Int`: numeric IPv4 host (inet_pton), blocking connect, then O_NONBLOCK; raises on failure with location "connectTo".
- `primSockRecv :: Int -> Int -> IO (Maybe Text)`: Nothing = would block; Just "" = EOF; raises otherwise.
- `primSockSend :: Int -> Text -> IO Int`: bytes written; -1 = would block; raises otherwise.
- `primSockClose :: Int -> IO ()`.
- **Gate:** build, golden (renumber only), exec.

## Phase B - library, example, harness, CI
- `lib/Network/Socket.hs`: `Socket` (abstract), `listenOn`, `accept`, `connectTo`, `recv` (parks on would-block; "" at EOF), `send`, `sendAll`, `close`, `socketFd` (for `waitReadOr`).
- exec test `tests/exec/socket_echo.hs`: a server task and a client task on the loopback in one program, deterministic under the scheduler.
- ahttpd over `Network.Socket`: no `foreign import`, no constants; `examples/httpd/README.md` updated.
- `scripts/run_httpd.sh`: drop the Darwin skip; on the concurrent-handlers failure dump the server's stderr (run the server with `AHC_SOCKET_DEBUG=1`).
- `.github/workflows/ci.yml`: run the httpd harness in the ubuntu suite job too.
- **Gate:** exec both GC modes, examples, httpd harness, conformance, golden, differential, repl, separate, export, unit.
