# M136-M138 Synchronous Exceptions - Implementation Plan

**Goal:** give AHC programs a way to recover from errors: `ioError`/
`userError` in the Prelude, `System.IO.Error`, and a base-compat
`Control.Exception` subset, GHC-oracled where a portable program can
observe them.

**Architecture:** the runtime grows a per-task chain of catch frames
(stack-allocated, unbounded) beside the existing boundary frames, an
`ahc_throw(node)` that unwinds to the nearest frame of either kind
after updating every thunk under evaluation to a rethrow thunk, and
a small set of exception-node primitives. `SomeException` and
`IOException` are wired opaque builtin types (the `Text` pattern);
everything else is Haskell in `prelude/` and `lib/`. Design:
`docs/exceptions-design-note.md`.

## As built - deviations from this plan (recorded after the fact)

- ArithException's DivideByZero index is 3 (base's order, 0-based), not 4.
- IOErrorType has an eleventh row, 10 InvalidArgument ("invalid argument"), for
  `exitWith (ExitFailure 0)` and errno EINVAL/ENAMETOOLONG/ELOOP; the errno map
  also covers EROFS, ETXTBSY, ENFILE, ENOMEM, EAGAIN, ENOTDIR.
- `IOErrorType` is a newtype over the index, not a `data` enum (constructor
  names are program-global in AHC).
- `ahc_throw` does NOT render at a boundary frame (review fix 2): the value is
  kept in `last_exc` and `ahc_last_error` renders on demand under its own frame.
- Handle names are kept after close and moved to a bounded ring on slot reuse;
  handles carry a generation tag so a stale Handle never aliases a new file.
- No frame is armed around `main`; an uncaught raise falls through to
  `exc_uncaught` at `err_depth == 0`.
- The eval frame costs three stores to push and one to pop, not two.
- Five oracled conformance programs landed, not three: the two Report fixes the
  library flushed out (ch03_14_unfailable_bind, ch04_05_mr_case_scrutinee) came
  with their own.

## Global constraints

- Oracle: GHC 9.4.8 (`~/.ghcup/bin/runghc`); conformance goldens are its stdout.
- Report scope: Prelude section 9 (`IOError`, `ioError`, `userError`), Library Report ch. 42 (`System.IO.Error`).
- Both GC modes must pass (`AHC_GC=own` and Boehm); own soak with `AHC_OWN_VERIFY=1`; TSan on the concurrency tests.
- Uncaught `ErrorCall`/`ArithException` text on stderr stays byte-identical (`ahc: error: MSG`, `ahc: divide by zero`); the two IOError exec goldens change deliberately.
- Hot-path budget: the eval-frame push/pop is two stores; `run_bench.sh` delta recorded in CHANGES, no other perf claim.
- `prelude/` and `lib/` are gate inputs: no background suite runs while Phase B edits them.
- New `Def_Global`s renumber golden `.core` ids: `run_golden.sh --update`, then verify the diff is renumber-only (`sed 's/_[0-9]\+//g'` both sides, diff empty).

- [ ] **Step 3: `ahc_throw`.**

```c
static AhcNode *rethrow_code(AhcNode **env) { ahc_throw(env[0]); return NULL; }
static AhcNode *mk_rethrow(AhcNode *exc) { AhcNode **e = ahc_env(1); e[0] = exc; return ahc_mk_thunk(rethrow_code, e); }

/* Update every thunk this task claimed above `stop` to re-raise exc,
   waking parked waiters so they observe the raise too. */
static void exc_abandon(AhcEvalFrame *stop, AhcNode *exc) {
  while (cur_task->eval_top != stop) {
    AhcEvalFrame *f = cur_task->eval_top;
    AhcNode *n = f->node, *r = mk_rethrow(exc);
    AhcTask *w = (AhcTask *)n->u.bh.waiters;
    __atomic_store_n(&n->u.ind, r, __ATOMIC_RELEASE);
    __atomic_store_n(&n->tag, AHC_IND, __ATOMIC_RELEASE);
#ifdef AHC_GC_OWN
    own_write_barrier(n);
#endif
    while (w) { AhcTask *nx = w->qnext; wake(w); w = nx; }
    cur_task->eval_top = f->prev;
  }
}

void ahc_throw(AhcNode *exc) {
  AhcCatch *c = cur_task->catch_top;
  cur_task->exc = exc;
  if (c && c->err_depth == cur_task->err_depth) {
    exc_abandon(c->eval_top, exc);
    cur_task->catch_top = c->prev;
    longjmp(c->jb, 1);
  }
  if (cur_task->err_depth > 0) {            /* a boundary frame */
    int d = cur_task->err_depth - 1;
    exc_render(exc, cur_task->err_msg, sizeof cur_task->err_msg);
    exc_abandon(cur_task->err_eval_top[d], exc);
    cur_task->catch_top = cur_task->err_catch_top[d];
    longjmp(cur_task->err_stack[--cur_task->err_depth], 1);
  }
  exc_uncaught(exc);                        /* main, outside ahc_run_main's frame: render, exit */
}
```

`wake` on a worker shell: waiters exist only on green-owned blackholes, so a worker's `exc_abandon` finds `w == NULL` - assert it.

- [ ] **Step 4: catch/throw/evaluate prims.**

```c
static AhcNode *io_catch(AhcNode **env, AhcNode *w) {
  AhcCatch c;
  c.prev = cur_task->catch_top; c.eval_top = cur_task->eval_top;
  c.err_depth = cur_task->err_depth;
  cur_task->catch_top = &c;
  if (setjmp(c.jb) == 0) {
    AhcNode *r = ahc_eval(ahc_apply(env[0], w));
    cur_task->catch_top = c.prev;
    return r;
  } else {
    AhcNode *exc = cur_task->exc;
    cur_task->exc = NULL;
    return ahc_eval(ahc_apply(ahc_apply(env[1], exc), w));
  }
}
static AhcNode *p_catch(AhcNode *act, AhcNode *h) { ...mk_fun(io_catch, [act,h])... }
static AhcNode *io_throw_io(AhcNode **env, AhcNode *w) { (void)w; fflush(stdout); ahc_throw(ahc_eval(env[0])); return NULL; }
static AhcNode *p_throw(AhcNode *e) { fflush(stdout); ahc_throw(ahc_eval(e)); return NULL; }
static AhcNode *io_evaluate(AhcNode **env, AhcNode *w) { (void)w; return ahc_eval(env[0]); }
```

`r` must be read before the frame pops? No - `ahc_eval` returned normally, the frame is simply popped. Note `setjmp` locals: `c` is not modified after `setjmp`, and `env`/`w` are parameters - no `volatile` needed.

```c
/* ONE text for uncaught exceptions, ahc_last_error, and the
   ErrorCall/IOError show instances' expectations (tests pin agreement). */
static void exc_render(AhcNode *exc, char *buf, size_t cap) {
  exc = ahc_eval(exc);
  switch (exc->u.con.contag) {
  case EXC_ERROR_CALL: sb "error: " + message; break;
  case EXC_ARITH: arith_names[code]; break;         /* "divide by zero" ... */
  case EXC_IO: [file ": "] [loc ": "] type_name [" (" desc ")"]; break;
  case EXC_EXIT: "ExitFailure N" / "ExitSuccess"; break;
  }
}
static void exc_uncaught(AhcNode *exc) {   /* noreturn */
  fflush(stdout);
  if (kind == EXC_EXIT) exit((int)code);
  exc_render(exc, buf, sizeof buf); fputs("ahc: ", stderr); fputs(buf, stderr); fputc('\n', stderr); exit(1);
}
```

```haskell
module Control.Exception
  ( SomeException, Exception (toException, fromException, displayException)
  , ErrorCall (..), ArithException (..), IOException, ExitCode (..)
  , throw, throwIO, catch, handle, try, evaluate
  , bracket, bracket_, finally, onException
  ) where
import System.Exit (ExitCode (..))

class Show e => Exception e where
  toException   :: e -> SomeException
  fromException :: SomeException -> Maybe e
  displayException :: e -> String
  displayException = show

instance Show SomeException where
  showsPrec p se = case primExcKind se of
    1 -> showsPrec p (ErrorCall (primExcMessage se))
    2 -> showsPrec p (toEnum (primExcCode se) :: ArithException)
    3 -> showsPrec p (primExcIO se)
    _ -> showsPrec p (codeToExit (primExcCode se))
instance Exception SomeException where toException = id; fromException = Just

data ErrorCall = ErrorCall String deriving (Eq, Ord)
instance Show ErrorCall where showsPrec _ (ErrorCall m) = showString m
instance Exception ErrorCall where
  toException (ErrorCall m) = primExcErrorCall m
  fromException se = if primExcKind se == 1 then Just (ErrorCall (primExcMessage se)) else Nothing

data ArithException = Overflow | Underflow | LossOfPrecision | DivideByZero | Denormal | RatioZeroDenominator deriving (Eq, Ord, Enum, Bounded)
instance Show ArithException where ... "arithmetic overflow" ...
instance Exception ArithException where toException = primExcArith . fromEnum; fromException se = if kind == 2 then Just (toEnum code) else Nothing
instance Exception IOException where toException = primExcFromIO; fromException se = if kind == 3 then Just (primExcIO se) else Nothing
instance Exception ExitCode where toException = primExcExit . exitToCode; fromException se = if kind == 4 then Just (codeToExit code) else Nothing

throw :: Exception e => e -> a
throw = primThrow . toException
throwIO :: Exception e => e -> IO a
throwIO = primThrowIO . toException
catch :: Exception e => IO a -> (e -> IO a) -> IO a
catch act h = primCatch act (\se -> case fromException se of Just e -> h e; Nothing -> primThrowIO se)
handle = flip catch
try act = catch (fmap Right act) (return . Left)
evaluate = primEvaluate
onException act what = primCatch act (\se -> what >> primThrowIO se)
bracket acq rel body = do a <- acq; r <- body a `onException` rel a; _ <- rel a; return r
bracket_ a r b = bracket a (const r) (const b)
finally act fin = do r <- act `onException` fin; _ <- fin; return r
```
