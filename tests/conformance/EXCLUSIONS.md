# Haskell 2010 Report features not exercised by this conformance subset

The suite covers what AHC implements; these Report features are known
gaps, excluded deliberately rather than tested weakly. Each entry is
the reason a conformance program does not exist for it.

| Report | Feature | Status |
|---|---|---|
| 5 | Module system corners | multi-module programs WORK (imports with qualified/as/hiding/lists, export lists incl. `T(..)`/`C(..)`, abstract types, cycle/ambiguity/not-exported errors); restricting the implicit Prelude import WORKS per Report 5.6.1 (`hiding`, only-lists, `import Prelude ()`, `qualified` - the explicit import replaces the implicit one, filters the qualified view too, and builtin syntax `()`/`[]`/`:`/tuples stays in scope; ext_prelude_*.hs conformance + bad_prelude_*.hs both-reject differentials). Still flat, and a clean compile ERROR where GHC would accept: same-named type SYNONYMS in two modules ("type 'T' is defined more than once") and same-named data CONSTRUCTORS in two modules ("constructor 'C' is defined more than once") - both namespaces are program-global, so qualified imports cannot disambiguate them; rename the colliding declaration. Code generation, C compilation and linking are separate and per-module (content-hash object cache; scripts/run_separate.sh); the FRONTEND stays whole-program by design - no interface files - which is what gives Report program-wide instance coherence for free |
| 6.4 | ~~`Rational` literals~~ WORK | float literals are exact decimal ratios through `fromRational` (`0.1 :: Rational` is `1 % 10`; at Double the pair takes ONE correctly-rounded conversion - ch06_04_rational_literals.hs); `Int` overflow promotes rather than wrapping, which Report 6.4 leaves undefined |
| lib | `Data.Array` is a monomorphic subset; `Read`'s instance set is partial | `Ratio a` and `Complex a` are POLYMORPHIC as of the polish milestones (lib_poly_ratio_complex.hs); Array stays at Int indices (list-backed, O(n) reads). `Read`/`reads`/`read` now live in the PRELUDE per Report 9.1 (`Text.Read` is a re-export facade), so `read` and `deriving Read` need no import (ch08_prelude_index_read.hs); the instance set is still Int/Integer/Bool/lists/pairs, and `readParen`/`lex`/`readList` are absent |
| 6.4.3 | `RealFrac` results at `Integer` | `Integral`/`Floating`/`RealFrac` are real classes (instances Int/Integer and Double; fromIntegral/(^)/(^^) polymorphic), but floor/ceiling/round/truncate return `Integer` rather than `Integral b => b` (GHC defaults `b` there anyway); `properFraction` works (result at Integer), and `RealFloat` is a real class at Double (isNaN/isInfinite/isNegativeZero/atan2 - ch06_04_realfloat.hs); decodeFloat/encodeFloat and radix introspection are absent |
| 6.3.4 | ~~`Enum` at Char/Double~~ WORKS | `['a'..'z']`, succ/pred/to/fromEnum at Char; Double numeric enumeration with GHC's k-indexed stepping and the half-step limit (ch06_03_enum_char_double.hs); Bool/Ordering enum now ride the enumeration-derive machinery (`[False ..]` works) |
| 11.1 | deriving covers ENUMERATIONS for Enum/Bounded/Ix/Read | `Eq`/`Ord`/`Show` derive for all shapes (ch11_01_derives.hs pins the enumeration derives); non-nullary deriving Enum/Bounded/Ix/Read is REJECTED at compile time ("all constructors must be nullary" - bad_derive_nonnullary.hs pins both-compilers-reject; GHC additionally accepts single-constructor Bounded/Ix products, which stay honestly unimplemented); deriving Read for non-enumerations is unimplemented |
| 3.14 | ~~`fail` at `Maybe`/`[]`~~ WORKS | refutable do-binds fail to Nothing / skip per the Report (ch03_14_faildo.hs); IO's fail errors, as GHC's does |
| ch. 4 | Class-hierarchy corners | `Functor`/`Applicative` (pure/`<*>`/`*>`/`<*`/`<$>`, ch04_applicative.hs) and `Read` work at Maybe/[]/IO, and `Either a` is Functor/Applicative/Monad as base has it (ch04_02_newtype_patterns.hs); `Monad` does NOT have `Applicative` as superclass (the 2010 shape - `return` and `pure` are separate but agree), BUT a Monad instance omitting `return` gets base's default: the whole-program frontend solves Applicative at the instance head and takes its `pure` (lib_monadplus.hs) |
| 4.2.3 | Newtype `seq` divergence | newtype constructor PATTERNS are irrefutable per the Report (`f (N _) = 1` accepts `undefined` - ch04_02_newtype_patterns.hs, the fix that lets some/many terminate on newtype parsers), but the wrapper is still a real runtime node, so `seq (N undefined) ()` is `()` where GHC (which erases newtypes) diverges; observable only through seq/`($!)` on an undefined-wrapped value |
| lib | `Control.Applicative` corners | Alternative (empty/`<|>`/some/many with the mutually recursive defaults), Const, WrappedMonad, ZipList, `<**>`/liftA/liftA2/liftA3/optional/asum all WORK (lib_control_applicative.hs); absent: WrappedArrow (no Arrow class), `Alternative IO` (exception-based in base), and asum is list-only (base's is Foldable) |

| lib | ~~`Data.Char` classification is ASCII-only~~ UNICODE | Classification and case mapping are table-exact against the oracle GHC on EVERY code point (tables generated from GHC itself by tests/gen_unicode.hs; lib_char_unicode_sums.hs checksums all 1114112); digit predicates stay ASCII as in GHC; `words` splits on Unicode isSpace. Strings are codepoint-correct end to end (ch02_06_unicode_strings.hs); the one deliberate divergence is invalid UTF-8 on INPUT, which decodes to U+FFFD instead of throwing (tests/exec/utf8_invalid_input.hs; docs/io-design-note.md "Text encoding") |
| lib | ~~`Data.List.foldl'` is `foldl`~~ WORKS | `seq` is a real primitive (force to WHNF), `($!)` builds on it, and `foldl'` keeps its accumulator evaluated (ch06_02_seq.hs values; tests/exec/seq_strict.hs pins the forcing itself) |
| lib | `Data.Bits` is monomorphic at `Int` | GHC's is `Bits a`-polymorphic; AHC's is often MORE permissive at defaulting boundaries, GHC-oracle tests annotate |
| lib | `Data.Ix` uses are not defaultable | AHC's Report-4.3.4 defaulting covers Prelude classes only; annotate `range (3, 7) :: [Int]` |
| lib | ~~`System.IO` handles~~ WORK | openFile/hClose/withFile, hPutStr/hPutStrLn/hPutChar/hPrint, hGetLine/hGetChar/hGetContents/hIsEOF/hFlush, writeFile/appendFile, stdin/stdout/stderr, IOMode with GHC's derived instances (ch07_io_handles.hs; error paths in tests/exec/handle_*.hs). Two documented divergences: `hGetContents` is STRICT (GHC's is lazy with semi-closed handles - portable programs must not touch a handle after it anyway), and `hClose` on a std stream flushes instead of closing (closing stdout would break the runtime's own writers) |
| lib | ~~`Control.Monad.guard` / MonadPlus~~ WORK | `guard :: Alternative f => Bool -> f ()` prunes list/Maybe do-blocks; MonadPlus is a real class (both methods default - the instances are empty-bodied, which now elaborates), plus msum and mfilter (lib_monadplus.hs); `MonadPlus IO` is absent, like `Alternative IO` |
| lib | `Data.Text` is a common subset; the `Text` NAME is wired in | ONE packed UTF-8 type (serving Text's and ByteString's roles; code-point API, byte-offset internals, O(1) byteLength/take/drop slices). The type name is visible without import like `Int` - GHC needs the import; the functions still need `import qualified Data.Text as T` in both. Eq/Ord/Show/pack/unpack/append/concat/intercalate/length/null/index/take/drop/splitAt/singleton match GHC's text package (lib_text_basic.hs); OverloadedStrings is UNCONDITIONAL (AHC ignores LANGUAGE pragmas; GHC-oracled programs carry the pragma - lib_text_overloaded.hs): string literals are `IsString a => a` with instances at Text and [Char] (the list instance's element is pinned to Char, so `"x" :: [Bool]` both-rejects - tests/corpus/bad_overloaded_string.hs), ambiguous literals default to [Char] (runghc's GHCi-style defaulting agrees), literal PATTERNS stay [Char]; a literal at Text compiles to a static packed CAF (zero runtime cost); Semigroup/Monoid are real Prelude classes with instances at [a]/Text/Ordering/Maybe/() (lib_semigroup_monoid.hs; base-compat beyond the 2010 Report, like Applicative), byteLength is AHC-only (tests/exec/text_slices.hs). `Text` crosses the FFI directly as `const char *` (M_Text - tests/exec/ffi_text.hs; all bindgen spokes map it to the host's native string), and System.IO has `hPutText`/`hGetContentsText` (GHC keeps these in Data.Text.IO) |

Runtime warnings differ by design: GHC's `-W` diagnostics are not
part of conformance (the oracle captures stdout only).
